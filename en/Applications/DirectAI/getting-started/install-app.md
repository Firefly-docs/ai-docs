# Install Apps

This section covers installing, updating, and uninstalling apps in DirectAI.

## Install from the App Store

1. Open the **App Store** from the client sidebar.

![App Store](./images/store-hq2.png)

2. Pick a target app from the list to view its description and version on the detail page. See [App Highlights](../app-intro/index.md) for the apps currently in the store.

3. Click install. The client handles the deployment automatically.

## Import Local App Packages

If you have an app package file, you can drag it into the app store window to import:

- New app: a notice shows "app imported and added to the store".
- Same-name app: a notice asks to replace the existing version; confirm to update.

## App Settings

Installed apps provide a settings page in the app store sidebar:

- **Client settings**: for example **Pin to sidebar**, which keeps the app in the sidebar for quick access.
- **App settings**: the app's own settings, presented and saved by the client, then applied to the device automatically.

## Update and Uninstall

- **Update**: import a newer app package and confirm the replacement in the store.
- **Uninstall**: uninstall from the app store or the app detail page — the app is removed from both the client and the device.

# 常见问题与故障排查

本章汇总 DirectAI 客户端在设备连接、应用安装和使用过程中的常见问题。

## 快速定位

| 问题现象 | 排查分类 |
|:---:|:---:|
| 扫描不到局域网设备，或 USB 连接后无反应 | [设备发现](#设备发现) |
| 登录失败或凭据失效 | [登录问题](#登录问题) |
| 应用页面空白、接口调用报错 | [应用运行](#应用运行) |
| 指标不显示、终端连不上 | [设备管理](#设备管理) |

## 设备发现

### 扫描不到局域网设备

- 确认电脑与设备连接到同一局域网，且网络未开启客户端隔离。
- 设备扫描依赖设备端服务。在设备上确认服务正在运行：

```bash
systemctl status directai-device-server
```

- 设备端服务未安装或未运行时，客户端无法发现该设备。从 [Firefly 官方资料中心](https://community.t-firefly.com/doc/download/428)获取设备端服务安装包，复制到设备安装（服务随包配置为开机自启）：

```bash
sudo dpkg -i ./firefly-directai-device-server_*.deb
```

- 在客户端重新点击「扫描」，或改用「USB 发现」。

### USB 连接后无反应

- 更换 USB 线或 USB 口，排除线材仅供电不传数据的情况。
- USB 连接后，登录和传输仍依赖设备端服务正常。

## 登录问题

### 登录失败

- 确认输入的是设备 Linux 账号的用户名和密码。
- 首次连接设备时，按客户端的提示完成设备确认，再输入账号密码登录。

### 保存的登录凭据失效

设备端修改密码或重置系统后，客户端会提示「保存的登录凭据已失效」。重新输入设备 Linux 账号的密码登录即可。

## 应用运行

### 应用页面空白或报错

- 确认设备仍处于连接状态。

### 设置保存后未生效

- 部分设置需要重启对应服务后生效，可在应用设置页查看服务状态。

## 设备管理

### 指标长时间不显示

指标来自设备服务端的快照，首次快照到达前客户端会显示等待状态。长时间无数据时检查设备端服务是否运行正常。

### SSH 终端连接失败

- 确认设备端 SSH 服务已开启。
- 网络切换或设备重启后，重新连接设备再试。

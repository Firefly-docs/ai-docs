# 快速开始

阅读本节，完成 DirectAI 的安装并连接您的第一台设备。

## 安装 DirectAI 客户端

从 [Firefly 官方资料中心](https://community.t-firefly.com/doc/download/429)获取 DirectAI 客户端安装包。

下载后运行安装程序，按向导完成安装并启动 DirectAI。

## 连接设备

启动客户端后进入登录页面，通过「网络发现」或「USB 发现」查找设备：

- **网络发现**：扫描局域网内的设备，适合设备已接入网络的场景。
- **USB 发现**：通过 USB 线发现连接的设备，适合首次配置或无网络环境。

![设备发现](./images/device-scan-800.png)

在扫描结果中选择目标设备，按提示确认后，输入设备的 Linux 用户名和密码完成登录。

![设备登录](./images/cert-trust-800.png)
